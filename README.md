## 🧩 The CRAFT Framework

Every prompt here follows **CRAFT** — 5 elements, always in this order:

| Element | Stands For | One Line |
|--------|-----------|---------|
| **C** | Context | Your project, domain, constraints |
| **R** | Role | The expert identity AI should adopt |
| **A** | Action | Exactly what you want produced |
| **F** | Format | Table / list / doc section / Jira-ready |
| **T** | Tone | Formal / analytical / plain English |

❌ Bad prompt: *"Write me some requirements."*  
✅ CRAFT prompt: Gets you a numbered BRD section with IDs, ready to paste into Confluence.

See [02 — CRAFT Framework](./02_CRAFT_Framework.md) for full examples.

## 🚀 How to Use This Playbook

1. **Pick your BA task** — find the matching section (requirements, process, stakeholder, etc.)
2. **Choose a prompt template** — each is labelled by use case and difficulty
3. **Apply CRAFT** — customise the Context and Action to your specific project
4. **Validate the output** — AI produces a draft; your judgment makes it professional
5. **Iterate** — refine the prompt if the output misses the mark; notes on iteration are included
